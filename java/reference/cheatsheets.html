The language, as specified (lessons 1–7)

Types & numbers

byte 8 · short 16 · int 32 · long 64 · char 16 unsigned · float/double IEEE 754 (N = 24/53) · boolean. Defaults 0 / false / null; locals have none (definite assignment). Wraparound silent; only int/long ÷ and % by 0 throw; floats never throw; NaN unordered (only != true); (int) NaN = 0; float→int saturates; integral narrowing keeps low bits; shifts masked (& 31 / & 63); ÷ truncates toward zero, % keeps the dividend's sign. Promotion: byte/short/char → int; b = b + 1 ✗, b += 1 ✓. Boxing cache: −128…127 (and Boolean, Byte, char ≤ 127) identical; null unboxing → NPE. Strings: UTF-16 units; constants interned; compact byte[] + coder; + → invokedynamic.

Initialization (JLS 12.4/12.5)

Class: triggered by new / static member use (declaring class only) / subclass init / reflection; not by constant variables, C.class, arrays. Order: ConstantValues → superclass → static initializers & fields in textual order; once, under the init lock; recursion returns defaults; failure → ExceptionInInitializerError, then NoClassDefFoundError. Instance: args → super(…)/this(…) → instance initializers & field initializers in textual order → body. Virtual call from a superclass constructor sees subclass fields at defaults.

Records, sealed, interfaces

record P(int x, int y): final class, private final fields, accessors x(), canonical ctor (compact form validates/normalizes), equals/hashCode/toString from components; can implement interfaces, declare static members and extra ctors; no instance fields. sealed interface S permits A, B; permitted types are final, sealed or non-sealed; enables exhaustive switch. Interfaces: default/static/private methods; class wins over default; conflicting defaults must be overridden (I.super.m()).

Generics

Erasure: T → bound (Object); one class file; List<String> and List<Integer> same class; no new T(), no T[], no primitives, no instanceof List<String>, no static T. Invariant: List<Integer> ⊄ List<Number>; arrays covariant (ArrayStoreException). PECS: ? extends T read, ? super T write. Bridge methods for covariant/erased overrides. Raw types → unchecked; heap pollution. Inference: diamond, target typing, lambdas.

Expressions, exceptions

Evaluation left to right; args left to right; a[i] = i++ evaluates a, i, then rhs. && || short-circuit; ?: unboxes if mixed. Checked (must declare/catch) vs unchecked (RuntimeException, Error). try-with-resources: resources closed in reverse order; suppressed exceptions (getSuppressed). finally overrides return/exception. Multi-catch types disjoint; catch of subclass before superclass. Precise rethrow.

Patterns & switch (JEPs 440/441)

Selector: int/char/short/byte or any reference type. Labels: constants, case null [, default], case Pattern [when guard], default. First applicable wins; dominance errors (supertype before subtype; unguarded before guarded; pattern before its constants); one match-all. Exhaustive: switch expressions, pattern/null/non-legacy switch statements — via sealed permits/enums; synthetic throwing default. default ≠ null. Record patterns nest, use var, never match null; accessor throws → MatchException. Pattern vars flow-scoped; no fall-through into pattern labels.

Lambdas & streams

Functional interface = one abstract method; lambda body captures effectively final locals; this = enclosing instance; no new scope for names. Method refs: Type::static, obj::inst, Type::inst (receiver = 1st arg), Type::new. Compiled via invokedynamic + LambdaMetafactory (hidden class). Streams: lazy intermediate (map/filter/sorted/flatMap/distinct/limit), terminal (collect/reduce/forEach/findFirst/anyMatch); single use; parallel() → common ForkJoinPool; Collectors.groupingBy/partitioningBy/joining/toMap.

Memory model (JLS 17)

synchronizes-with: unlock→lock (same monitor), volatile write→read, start→first action, last action→join/isAlive, interrupt→detection, default writes→all. hb = po ∪ sw (∪ ctor→finalizer), transitive. Data race = conflicting accesses unordered by hb. Correctly synchronized ⇔ SC executions race-free ⇒ all executions SC. sleep/yield: no sync semantics. final fields: freeze at ctor exit; safe even through a race if this doesn't escape. long/double non-volatile may tear; references atomic; byte tearing forbidden. wait: hold lock, loop; notify not remembered.

The JVM (lessons 8–12)

Class file

CAFEBABE · minor/major (65 = 21; 45–55 any minor; ≥ 56 minor 0; preview = minor 65535) · constant pool (1-indexed; long/double take 2) · access flags · this/super/interfaces · fields · methods · attributes: Code (max_stack, max_locals, code, exception table, StackMapTable, LineNumberTable), ConstantValue, Exceptions, Signature, BootstrapMethods, InnerClasses, NestHost/NestMembers, Record, PermittedSubclasses, SourceFile, annotations. Descriptors: I J Z B C S F D V, Lx/Y;, [ .

Bytecode

1-byte opcode + big-endian operands; only *switch padded. Types i l f d a (b s c for arrays/pushes); boolean/byte/char/short as int; category 2 = long/double (2 slots). Families: load/store, const/push/ldc, arith (only int ÷ % throw), conv (i2l, d2i saturating), object (new, getfield, checkcast), stack (dup, pop2, swap), control (if_icmpge, goto, tableswitch dense / lookupswitch sparse, lcmp/fcmpl/dcmpg), invoke*, *return, athrow, monitorenter/exit, iinc. Exceptions: table scanned in order; finally duplicated; verification by StackMapTable.

Loading & linking (JVMS 5)

Loaders: bootstrap → platform → app (parent-first); defining vs initiating; identity <name, loader>; run-time package/module; loading constraints (LinkageError). Derivation errors: ClassFormatError, UnsupportedClassVersionError, NoClassDefFoundError, ClassCircularityError, IncompatibleClassChangeError. Linking: verify → prepare (defaults) → resolve (lazy, memoized; per-instruction for indy). Lookup: fields C→superinterfaces→superclass; methods C→superclasses→maximally-specific interface methods. Access: public+module, package-private same run-time package, protected, private nestmates.

Invocation (JVMS 5.4.5–6, 6.5)

invokestatic; invokespecial (<init>, super, private); invokevirtual/invokeinterface: resolve compile-time method, then select: private → itself; else receiver class, superclasses, then unique non-abstract maximally-specific interface method. Override needs same name/descriptor, not private, target public/protected or package-private in the same run-time package. invokedynamic: bootstrap(Lookup, name, MethodType, static args) → CallSite (non-null, matching type, else BootstrapMethodError), once per instruction; lambdas (LambdaMetafactory), + (StringConcatFactory), records (ObjectMethods), pattern switch (SwitchBootstraps). MH kinds: getField/getStatic/putField/putStatic/invokeVirtual/invokeStatic/invokeSpecial/newInvokeSpecial/invokeInterface.

HotSpot JIT

Levels 0 interp · 1 C1 · 2 C1+counters · 3 C1+MDO · 4 C2. Paths: 0→3→4 (common), 0→2→3→4 (C2 busy), 0→(3→2)→4, 0→3→1 (trivial), 0→4 (deopt w/o reprofile); deopt → 0. Thresholds: T3 inv 200 or (>100 & inv+be > 2000); T4 inv 5000 or (>600 & > 15000); OSR be 60000/40000. Inlining: MaxInlineSize 35, FreqInlineSize 325, InlineSmallCode 1000, MaxInlineLevel 15, recursive 1. CHA/profile devirtualization, uncommon traps, implicit null checks, escape analysis (scalar replacement, lock elision), range-check elimination, unrolling, vectorization, intrinsics. Safepoint polls at returns/back-edges; handshakes. PrintCompilation: % OSR, s sync, ! handlers, n native.

Objects & GC

Header: mark word (unused 25 | hash 31 | · | age 4 | · | lock 2: 01 free, 00 locked, 10 monitor, 11 marked) + Klass*/narrowKlass. TLAB bump allocation. Generational: young (eden/survivors, age++) → old; remembered set via write barrier (card 512 B; ZGC bitmaps). Default: G1 if ≥ 2 CPUs & ≥ 2 GB, else Serial. Serial / Parallel (throughput) / G1 (regions, pause goal 200 ms, humongous ≥ half region) / ZGC (concurrent, µs pauses, TB heaps) / Generational ZGC (-XX:+ZGenerational; colored pointers low bits; load barrier strips/remaps; store barrier colors + remembered set + SATB; double-buffered bitmaps; 2-pass young GC; dense regions aged in place; pauses < 1 ms). Refs: soft, weak, phantom (Cleaner); finalize deprecated.

Java 21: virtual threads and new features (lessons 13–17)

Virtual threads (JEP 444)

Little's Law: concurrency = throughput × latency. Virtual thread = Thread not tied to an OS thread; M:N; carrier = platform thread it's mounted on; unmount on blocking JDK ops; no affinity, no time-slicing, not cooperative. Help when tasks » cores and not CPU-bound; "not faster, just more". Never pool; Semaphore to throttle; ThreadLocal caution. Pinning: synchronized / native → carrier blocked, no compensation → use ReentrantLock; JFR VirtualThreadPinned (20 ms), -Djdk.tracePinnedThreads. Captured carriers (file I/O, Object.wait) → compensation up to maxPoolSize. Always daemon, NORM_PRIORITY, "VirtualThreads" group, no public ctor: Thread.ofVirtual(), startVirtualThread, newVirtualThreadPerTaskExecutor. Stacks = heap stack chunks, not GC roots (G1 humongous limit). jcmd Thread.dump_to_file -format=json. Avoid -XX:+PreserveFramePointer.

Internals

Scheduler: ForkJoinPool(parallelism = CPUs, maxPoolSize = max(par, 256), minRunnable = max(par/2, 1), asyncMode FIFO, 30 s keepalive), CarrierThread extends ForkJoinWorkerThread; unparker STPE for timed park. States: NEW 0 → STARTED 1 → RUNNING 2 → PARKING 3 → PARKED 4 / PINNED 5; TIMED_ 6–8; UNPARKED 9; YIELDING 10 / YIELDED 11; TERMINATED 99. runContinuation: CAS → RUNNING, mount (carrier.setCurrentThread(vt)), cont.run, unmount, afterDone/afterYield. park: permit? else yield; fail → parkOnCarrierThread. Continuation.Pinned: NATIVE, MONITOR, CRITICAL_SECTION. Freeze/thaw ~100–150 ns; fast path memcpy compiled frames into StackChunk, bottom frame patched with return barrier; slow path interpreted frames + barriers.

Structured concurrency & scoped values (preview)

try (var s = new StructuredTaskScope.ShutdownOnFailure()) { var a = s.fork(…); var b = s.fork(…); s.join().throwIfFailed(); use(a.get(), b.get()); } Owner-only fork/join/shutdown/close; join before results (IllegalStateException on close otherwise); shutdown interrupts; ShutdownOnSuccess.result(); handleComplete for custom policies; ensureOwnerAndJoined; joinUntil → TimeoutException → shutdown. Scope tree by nesting. static final ScopedValue<T> K = ScopedValue.newInstance(); ScopedValue.runWhere(K, v, () -> …); K.get()/isBound()/orElse; rebinding nests; inherited by forked subtasks; StructureViolationException on mismatched nesting. --enable-preview.

Toolkit

Monitor: reentrant, no timeout/fairness; inflates on contention/wait; pins virtual threads. ReentrantLock: tryLock/timeout/interruptible/fair/Conditions; same memory effects. RW lock (downgrade only), StampedLock (optimistic; non-reentrant), Semaphore, CountDownLatch, CyclicBarrier, Phaser, Atomic*/LongAdder/VarHandle. AQS: int state + tryAcquire/tryRelease (+Shared) + FIFO queue + LockSupport permits (max 1, spurious). ThreadPoolExecutor: extra threads only when the queue is full. ForkJoinPool: work stealing, LIFO/FIFO(asyncMode), common pool (CPUs−1), ManagedBlocker. Choose: I/O-heavy many tasks → virtual threads; CPU → ~cores platform threads/parallel streams; slow guarded op → ReentrantLock; throttle → Semaphore; context → ScopedValue.
