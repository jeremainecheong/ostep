Java 21, from the specification down to the carrier thread

Seventeen interactive lessons in three tracks. Track A reads the Java Language Specification the way a compiler does — types, initialization order, records and sealed types, erasure, evaluation order, patterns, lambdas, and the memory model. Track B reads the JVM Specification and HotSpot's own source — class files, loading and initialization, the invoke instructions, tiered compilation, the object header and Generational ZGC. Track C is Java 21's headline: virtual threads as JEP 444 specifies them and as VirtualThread.java implements them, structured concurrency, scoped values, the concurrency toolkit, and the full JEP list. Every claim was checked against the primary text.

How to use this course

1. One lesson per sitting

Each takes 30–50 minutes: read, play with the simulator until you can predict it, paste the code block into jshell or a scratch file (JDK 21; some blocks need --enable-preview), flip the cards, then do the quiz from memory. Tick the objectives only when you could explain them to someone else.

2. Then read the source

Every lesson links its primary source — a JLS/JVMS chapter, a JEP, or the JDK file it quotes (VirtualThread.java, markWord.hpp, compilationPolicy.cpp…). The lesson is the map; the source has the edge cases.

3. Space it out

Redo a quiz two days later and again after a week. The cheat sheets are for the fast pass, the glossary for vocabulary, My notes for what you wrote. Ask me in the chat for mixed quizzes across lessons.

What's verified, and what isn't

Numbers in the JVM and Loom tracks — tier thresholds, inlining limits, the mark-word layout, the class-file version rule, scheduler defaults, VirtualThread state constants, HashMap/ArrayList constants — were read from the JDK 21u sources, not from memory; JEP 444, JEP 439, JEP 441, JLS chapter 17 and JVMS chapters 2 and 5 were fetched in full. VERIFIED-FACTS.md in the workspace lists them with file paths. Structured concurrency and scoped values are described as they are in JDK 21 (preview); later JDKs changed their APIs. HotSpot details are JDK 21's (e.g. biased locking already removed, non-generational ZGC still the ZGC default).
