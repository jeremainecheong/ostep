# Mission

Learn Java 21 from its specifications and its implementation, then master the release's defining feature — virtual threads — down to the source.

- **Track A — the language (JLS 21)**, lessons 1–7: types and conversions; class/instance initialization order; records, sealed types, interfaces; generics and erasure; evaluation order, exceptions, switch and patterns; lambdas/method refs/streams; the memory model (happens-before, final fields).
- **Track B — the JVM (JVMS 21 + HotSpot)**, lessons 8–12: class files and bytecode; loading/linking/initialization and class loaders; frames and the five invoke instructions incl. invokedynamic; tiered JIT and deoptimization; object headers, GC and Generational ZGC.
- **Track C — Java 21 and Loom**, lessons 13–17: virtual threads per JEP 444; VirtualThread/Continuation internals; structured concurrency and scoped values (preview); the concurrency toolkit; the 15 JEPs.

Learner: visual + interactive; wants everything important, structured, mobile-friendly, deployed as a website with directory and notes; insists on grounding in real source text.
