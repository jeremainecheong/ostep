# Mission

Learn Python 3.13 the way its authors specify it and its implementers built it, then apply the same rigour to the two dominant DataFrame libraries.

- **Track A — the language, as specified** (lessons 1–10): read *The Python Language Reference* §2–§8 and the typing PEPs so that behaviours (aliasing, UnboundLocalError, `-2**2`, descriptors, MRO, `finally`+`return`, pattern matching, imports) are *predicted*, not memorised.
- **Track B — CPython 3.13 internals** (11–14): compiler pipeline and code objects; the specializing adaptive interpreter and the experimental JIT; reference counting, immortal objects and the cycle GC with real thresholds; the GIL and the free-threaded build (PEP 703).
- **Track C — pandas vs Polars** (15–20): data models, selection, expressions and the lazy engine, groupby/joins/reshaping, time series, performance and scale — every comparison sourced from the pandas 3.0 and Polars user guides.

Learner: visual + interactive; wants everything important, structured, mobile-friendly, as a website with a directory and note-taking; insists on grounding in the actual source text ("literally grep the entire pdf").
