The language, as specified (lessons 1–10)

Objects

identity (fixed, is, id()) · type (fixed, type()) · value (mutable types only). Immutable container holding a mutable object: value can change, container is still immutable. a = 1; b = 1 may share; c = []; d = [] must not; e = f = [] shares. Equal ⇒ same hash; __eq__ without __hash__ ⇒ unhashable. dict order = insertion (3.7+).

Lexing & expressions

Indent stack → INDENT/DEDENT; tabs to multiples of 8; mixed ⇒ TabError. 35 keywords + soft: match case _ type. Precedence (high→low): atoms · x[i] x() x.a · await · ** · unary +−~ · * @ / // % · + − · shifts · & · ^ · | · comparisons (chained, one level) · not · and · or · if-else · lambda · :=. -2**2=-4 · 2**-1=0.5 · 7//-2=-4 · -7%3=2. Left-to-right, except assignment: RHS first. and/or return operands.

Scopes

Bound anywhere in a block ⇒ local everywhere in it (compile time) ⇒ UnboundLocalError. Resolution: local → enclosing functions → global → builtins. global: module ns; nonlocal: nearest enclosing function (else SyntaxError). Class body: names not visible in methods/comprehensions; unbound locals → globals; annotation scopes see the class. type X = … and type-param bounds are lazy.

Special methods

x+y: type(x).__add__ → NotImplemented → type(y).__radd__ (first if type(y) is a subclass overriding it) → TypeError. x += y: __iadd__ then fallback. Construction: __new__ (static; creates) then __init__ only if an instance of cls was returned. repr (official) vs str (falls back to repr). bool: __bool__ → __len__ → True. Sequences raise IndexError; mappings KeyError; __missing__ on dict subclasses. __exit__ true ⇒ suppress. Implicit lookup uses type(obj).

Attribute lookup (object.__getattribute__)

  1. data descriptor on type (has __set__/__delete__)
  2. instance __dict__
  3. non-data descriptor (__get__ only: functions → bound methods)
  4. class variable
  5. AttributeError → __getattr__ if defined

a.x → type(a).__dict__['x'].__get__(a, type(a)); A.x → __get__(None, A). property = data; __slots__ = member descriptors, no __dict__; __set_name__(owner, name) at class creation.

Classes

class statement: resolve __mro_entries__ → determine metaclass (most derived) → __prepare__ → exec body → metaclass(name, bases, ns) (type.__new__: __set_name__, then __init_subclass__). C3: L[C] = C + merge(L[B1]…L[Bn], [B1…Bn]) — take first head not in any tail; none ⇒ TypeError. super() walks type(self).__mro__ after the current class. ABCs: register / __subclasshook__ (virtual subclasses).

Calls, generators, coroutines

Slots: positionals first, keywords by name (filled twice ⇒ TypeError), defaults (evaluated once at def) for the rest, *args/**kw for extras, missing ⇒ TypeError. Generator: next/send(v)/throw(e)/close() (GeneratorExit); return v ⇒ StopIteration(v); yield from/await evaluate to it; StopIteration inside ⇒ RuntimeError (PEP 479). Awaitable: coroutine or __await__ iterator; await twice ⇒ RuntimeError.

Statements

Unpacking: one starred target, needs ≥ len(others). Augmented: __iadd__ then rebind (tuple[0] += […] mutates then raises). try: except in order (as-name cleared) → else only on clean completion → finally always; return in finally discards the exception; exception in finally gets __context__. raise X from Y; except* splits ExceptionGroups (no return/break/continue). with: enter → bind → suite → __exit__(type, value, tb). match: literal (==, None/True/False by is), capture, _, value (dotted), OR (same names), AS, sequence (not str/bytes; one star), mapping (extra keys ignored), class (isinstance; __match_args__); guard after match; one irrefutable case, last.

Import & typing

Import: sys.modules → sys.meta_path finders (find_spec → ModuleSpec/None) → load (module inserted in sys.modules BEFORE exec; removed on failure) → bind name. Path finder: sys.path / __path__, sys.path_hooks, sys.path_importer_cache; __pycache__/*.cpython-313.pyc (mtime+size or hash). Relative imports need __package__ (python -m). Typing timeline: 484 (3.5) 526 (3.6) 544 (3.8) 585 (3.9) 604/612 (3.10) 646/673 (3.11) 695 (3.12) 696/702/705/742 (3.13) 649 (3.14). Runtime never enforces hints.

CPython 3.13 internals (lessons 11–14)

Pipeline

tokenizer → PEG parser (python.gram → parser.c) → AST (Python.asdl) → symtable.c → compile.c/flowgraph.c (CFG, constant folding, jump threading, dead code, superinstructions, stack depth) → assemble.c → code object → marshal → .pyc. optimize=1 drops asserts; 2 also docstrings.

Code & bytecode

Code unit = 8-bit opcode + 8-bit oparg; EXTENDED_ARG (≤ 3) extends; inline CACHE units follow specializable instructions (first = counter). co_code public/immutable; co_code_adaptive private/mutable. Zero-cost exceptions: co_exceptiontable (range → target, depth, lasti). Stack machine: LOAD_FAST, LOAD_CONST, BINARY_OP, CALL n, RETURN_VALUE; co_stacksize precomputed.

Eval loop

_PyEval_EvalFrameDefault: _PyInterpreterFrame on the thread data stack (localsplus = locals + eval stack); PyFrameObject lazily. Computed gotos. JUMP_BACKWARD/RESUME check eval_breaker (signals, GIL drop, GC). Generated from bytecodes.c → generated_cases.c.h.

Specialization (PEP 659)

Adaptive instruction counts down in cache → _Py_Specialize_X inspects operands → rewrites to a specialized form + fills cache (type version, dict version, function version) → guard each execution → deopt with back-off on failure. Families: LOAD_ATTR (INSTANCE_VALUE, SLOT, MODULE, CLASS, PROPERTY, METHOD_*…), LOAD_GLOBAL (MODULE/BUILTIN), BINARY_OP (ADD/SUB/MUL INT/FLOAT/UNICODE), CALL (PY_EXACT_ARGS, BUILTIN_*, METHOD_DESCRIPTOR_*, LEN, ISINSTANCE…), FOR_ITER (LIST/TUPLE/RANGE/GEN), COMPARE_OP, TO_BOOL, STORE_ATTR/SUBSCR, UNPACK_SEQUENCE. 10–60% speedups. Stable types at a site ⇒ fast.

Tier 2 / JIT (PEP 744)

Hot loops (JUMP_BACKWARD counters) → trace of micro-ops → optimizer (remove guards/refcounts, constants) → executor with side exits → optional copy-and-patch machine code from build-time LLVM stencils (~900 py + 500 C lines). Off by default; --enable-experimental-jit; PYTHON_JIT=0/1.

Memory

Refcounting: INCREF/DECREF, zero ⇒ dealloc now; cycles need GC. Immortal (PEP 683): fixed refcount (None, True/False, small ints, interned str, static types). Cycle GC: gc_refs = refcnt − internal refs; >0 ⇒ root; propagate reachability; weakrefs → tp_finalize once (PEP 442) → tp_clear. Generations 0/1/2, thresholds (2000, 10, 10), +25% long-lived rule, gc.freeze(). pymalloc ≤ 512 B. List growth (n + n>>3 + 6) & ~3 → 0 4 8 16 24 32 40 52 64 76. dict: indices (1/2/4/8-byte) + dense ordered entries; min 8; ≤ 2/3 full; split tables.

GIL

One thread runs bytecode; released for I/O and by Py_BEGIN_ALLOW_THREADS. Boolean + mutex + condvar; switch interval 5 ms (DEFAULT_INTERVAL 5000 µs, sys.setswitchinterval); gil_drop_request via eval_breaker; forced switching. Motivation: non-atomic refcounts and containers. CPU-bound threads ⇒ no speedup; use processes / GIL-releasing native code / sub-interpreters (per-interpreter GIL, 3.12).

Free-threaded 3.13 (PEP 703)

python3.13t (--disable-gil); PYTHON_GIL / -X gil; sys._is_gil_enabled(). Biased RC (ob_ref_local + atomic ob_ref_shared) · immortalization (also functions/code/modules/types when threads start) · deferred RC · ob_mutex critical sections · mimalloc · stop-the-world non-generational GC · Py_mod_gil (missing ⇒ GIL re-enabled + warning). ~40% single-thread overhead (specializer disabled). Containers "behave like the GIL" but use Locks.

Group by & joins

Joins: inner (default both), left, right, outer/full (+coalesce), cross, semi/anti (Polars), merge_asof/join_asof, join_where. pandas discards indexes when joining on columns; many-to-many ⇒ Cartesian; validate=, indicator=True. concat: axis/join/ignore_index vs how=vertical/horizontal/diagonal.

Reshape & time

Time: Timestamp/Period/Timedelta/DateOffset; 3.0 default unit us (2.x ns); resample(closed/label/origin), rolling("7D"), tz_localize/tz_convert vs Date/Datetime(unit, tz)/Duration/Time; group_by_dynamic(every, period, offset; sorted!), rolling(index_column, period), upsample+fill_null, replace_time_zone/convert_time_zone.

Scale

Load less (columns=/usecols, scan+select) · efficient dtypes (uint8 vs int64 = 8×; category/Categorical; Arrow strings) · Parquet · chunking / streaming · vectorize (eval/query, Numba; expressions, map_batches) · lazy API (Polars only). Polars threads never take the GIL; pandas single-threaded regardless of 3.13t. multiprocessing + Polars ⇒ spawn. Interop via Arrow: from_pandas / to_pandas / to_arrow.
