# Python 3.13 course

Interactive course in three tracks (language spec · CPython internals · pandas vs Polars), 20 lessons, built from primary sources. Open `index.html` (or the built copy where assets are inlined). Runs real Python in the browser via Pyodide. Notes and quiz scores are stored in the browser (`py313:` keys); export from `notes.html`.

Build a self-contained copy: `python3 build.py <outdir>`.
