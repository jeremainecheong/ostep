Virtualization: the CPU (ch 4–10)

Process

Machine state = address space (code, heap, stack) + registers (PC, SP, …) + I/O info (fds 0/1/2 …). States: Running ↔ Ready (deschedule/schedule); Running → Blocked (I/O start); Blocked → Ready (I/O done); Zombie until wait().

fork(): child gets 0, parent gets child PID · exec(): replace image, never returns · wait(): block for a child. Shell: fork → rewire fds → exec.

Limited direct execution

  • User mode vs kernel mode; syscall = number in register + trap; return-from-trap lowers privilege.
  • Boot: install trap table, start timer. Timer interrupt = non-cooperative control.
  • Context switch: hardware saves user regs → kernel stack; OS switch() saves kernel regs → proc struct, swaps kernel stacks.

Book numbers: 100/10/10 → FIFO 110, SJF 50; late arrivals SJF 103.33, STCF 50.

MLFQ rules

  1. Higher priority runs.
  2. Equal priority → RR with that queue's slice.
  3. New job → top queue.
  4. Use up allotment at a level (however many yields) → demote.
  5. Every S: boost all to top.

Fixes: starvation (rule 5), gaming (rule 4 accounting). Solaris TS: 60 queues, 20 ms–hundreds of ms, boost ~1 s.

Proportional share

Lottery: tickets = share; random draw; currency/transfer/inflation. Stride: stride = big/tickets; run lowest pass; pass += stride (100/200/40 example). CFS: run lowest vruntime; slice = weight/Σweight × sched_latency (48 ms), ≥ min_granularity (6 ms); vruntime += 1024/weight × runtime; nice −20…19 → weights 88761…15; red-black tree.

Multiprocessor

Cache coherence (bus snooping) keeps correctness; cache affinity drives performance; kernel needs locks. SQMS: simple, balanced, poor scaling/affinity. MQMS: scales, affinity, needs migration / work stealing. Linux: O(1), CFS, BFS.

Virtualization: memory (ch 13–23)

Goals & mechanisms

Transparency, efficiency, protection. Base/bounds: PA = VA + base if VA < bounds. Segmentation: per-segment base/size/grow bit/protection; top bits select segment (code 00, heap 01, stack 11); stack offset = off − max → negative. External fragmentation.

14-bit: heap VA 4200 → 34K + 104 = 34920 · stack VA 15K → 28K − 1K = 27K

Allocators (ch 17)

Header {size, magic} before each block; free list inside free space; split & coalesce. Best fit (slivers), worst fit (bad), first fit (fast), next fit. Segregated lists / slab (Bonwick), binary buddy (easy coalescing, internal frag).

Paging

VPN = VA >> offset_bits · PTE = mem[PTBR + VPN×size] · PA = PFN<<bits | offset

Linear table: 32-bit, 4 KB pages, 4 B PTE → 2²⁰ × 4 = 4 MB/process. PTE bits: valid, protection, present, dirty, reference (x86: P, R/W, U/S, A, D, PFN). Costs: space + one extra memory access per reference.

TLB

Hit → use PFN. Miss → HW walk (x86) or OS handler (MIPS; return to same instruction). Locality: spatial (array walk = 70% in book's example), temporal. Context switch: flush or ASID. Replacement: LRU/random. MIPS R4000 entry: VPN, PFN, ASID, G, C, D, V.

Smaller tables

Bigger pages (internal frag) · paging+segments · multi-level: page directory → page-table pages; PDE valid iff any PTE valid; TLB miss costs 2+ loads (time-space trade-off) · inverted (hash) · swap the tables.

16 KB, 64 B pages: 14 bits = 4 PDidx + 4 PTidx + 6 offset

Swapping & policies

AMAT = T_M + P_miss × T_D (100 ns + 0.1×10 ms ≈ 1 ms)

Present bit; page fault → OS handler; watermarks + swap daemon; clustering. OPT (Belady MIN) 6/11 on 0,1,2,0,1,3,0,3,1,2,1 (3 frames); FIFO 4/11, Belady's anomaly; LRU 6/11; clock = use bit + hand; consider dirty bit. Workloads: no-locality, 80-20 (LRU wins), looping-sequential (LRU/FIFO 0%). Thrashing → admission control / OOM killer.

Real systems

VAX/VMS: 512 B pages, P0/P1/S regions, page 0 invalid, segmented FIFO + global clean/dirty lists, clustering, demand zeroing, COW. Linux: 3 GB/1 GB split (0xC0000000), kernel logical (kmalloc, contiguous) vs virtual (vmalloc), huge pages 2 MB/1 GB, 2Q page cache (inactive/active), NX, ASLR, KPTI.

Concurrency (ch 26–33)

Threads & the race

mov counter,%eax · add $1,%eax · mov %eax,counter

Shared: code, heap. Private: PC, regs, stack. Race → indeterminate; critical section needs mutual exclusion via atomic primitives. Why in OS class: the kernel was the first concurrent program.

pthreads

pthread_create(&t, NULL, fn, arg); pthread_join(t, &ret);
pthread_mutex_lock/unlock/trylock; pthread_cond_wait(&c,&m)/signal/broadcast
gcc -pthread

Guidelines: keep it simple, minimize interaction, init locks/CVs, check return codes, don't pass stack pointers to threads, always use CVs to signal.

Condition variables

  • Need lock + CV + state variable.
  • Hold the lock when waiting and signalling.
  • Always while (Mesa semantics, spurious wakeups).
  • Producer/consumer: one lock, two CVs (empty, fill), while loops.
  • Covering condition → broadcast.

Semaphores

sem_init(&s,0,N); sem_wait: value--, sleep if <0; sem_post: value++, wake one

Init 1 = lock; 0 = ordering (join); N = resources/throttling. Bounded buffer: empty=MAX, full=0, mutex=1 inside the waits. Reader-writer (starves writers). Dining philosophers: break the cycle. Zemaphore = lock + CV.

Bugs & events

Lu et al.: 74 non-deadlock (97% atomicity/order violations) + 31 deadlock. Deadlock needs: mutual exclusion, hold-and-wait, no preemption, circular wait. Prevent: lock ordering (address trick), acquire-all under a global lock, trylock (livelock → random back-off), lock-free CAS. Avoid: Banker's scheduling. Detect & recover (databases). Events: loop over select()/poll(); no locks; never block → async I/O (aio_read, signals); continuations for state.

Persistence (ch 36–50)

Devices & disks

Registers: status/command/data. Poll → interrupts (coalescing, livelock risk) → DMA. PIO vs memory-mapped I/O. Drivers > 70% of Linux. Disk: 512 B sectors; T_I/O = seek + rotation (½ rev = 60000/RPM/2 ms) + transfer. Cheetah 15K: 4 KB random ≈ 6 ms → 0.66 MB/s; sequential ≈ 125 MB/s. Scheduling: SSTF (starvation), SCAN/C-SCAN/F-SCAN, SPTF (in drive), I/O merging, anticipatory.

Files & vsfs

open → fd → open-file-table entry (offset, refcnt, inode); fork/dup share it. lseek changes offset only. fsync (maybe dir too). rename atomic. link/unlink; symlinks dangle. Permission bits rwx × owner/group/other. vsfs: S | i | d | I×5 | D×56; inode 256 B, 12 direct + indirect (×1024) + double + triple → 48 KB / 4 MB / 4 GB. Read /foo/bar: 5 reads to open; per block read inode, data, write inode. Create: 10 I/Os. Page cache; write buffering 5–30 s.

FFS · journaling · LFS

FFS: cylinder/block groups; dirs where few dirs; files with their dir; large-file exception (amortize); sub-blocks; long names; symlinks; rename. Journaling: data mode = journal write (TxB,I,B,Db) → commit (TxE) → checkpoint → free; ordered metadata = data write → journal metadata → commit → checkpoint → free; checksums; revoke records; circular log; batching. fsck: superblock, free blocks, inode state/links, duplicates, bad blocks, directories — slow, metadata only. LFS: segments, imap, CR (~30 s), cleaner + segment summary block, hot/cold, roll forward.

SSDs & integrity

Read page (25–75 µs) · program page (200–1350 µs) · erase block (1.5–4.5 ms). Log-structured FTL, mapping table (page-level 1 GB/TB → hybrid/cached), GC, trim, wear leveling, write amplification. SSD random ≈ 40–290 MB/s vs HDD 2. LSE (9.4%/1.4%) vs corruption (0.5%/0.05%). Checksums: XOR, addition, Fletcher, CRC; + physical ID (misdirected), write-verify or parent checksums (lost, ZFS); scrubbing; 8 B per 4 KB ≈ 0.19%.

Distributed · NFS · AFS

Acks + timeouts + sequence numbers; RPC stubs, XDR. NFS: stateless, file handle = volume + inode + generation; LOOKUP/READ/WRITE…; idempotent retry; flush-on-close; attribute cache 3 s; server commits before ack; VFS/vnode. AFS: whole-file caching; v1 TestAuth overload (20 clients); v2 callbacks, FIDs, dir caching (50 clients); last closer wins; crash → revalidate; global namespace, ACLs, volumes.

Security & VMMs (ch 53–57, App B)

Goals & principles

Confidentiality · Integrity · Availability. Policy vs mechanism. Saltzer–Schroeder: economy of mechanism, fail-safe defaults, complete mediation, open design, separation of privilege, least privilege, least common mechanism, acceptability.

Authentication

Identity inherited from parent; login process; setuid. Know (password → salted cryptographic hash; dictionary attacks) · Have (smart card, phone, one-time code) · Are (biometrics: false positives/negatives) · MFA. Non-humans: keys/certificates.

Access control

Reference monitor, complete mediation. Access matrix: ACL = column per object (UNIX 9 bits condensed; groups); capability = row per subject (fd = capability; delegation; hard revocation). DAC vs MAC; RBAC; type enforcement. Failures come from policies, not mechanisms.

Cryptography

Symmetric (AES, fast, key distribution) · public/private (RSA: public-key encrypt = secrecy, private-key encrypt = authentication/signature; slow → exchange session keys) · hashes (SHA-3; SHA-1 broken). Security lives in the key; don't roll your own. At-rest: full-disk encryption. Cryptographic capabilities.

Distributed security

Certificates (X.509) from a CA bind name → public key. Passwords only over an authenticated encrypted channel. TLS (not SSL): negotiate, verify cert, Diffie-Hellman session key — authenticated or man-in-the-middle. Use HTTPS, SSH, Kerberos.

VMMs

Trap-and-emulate: guest OS de-privileged; privileged ops trap to the VMM; x86 non-trapping instructions → binary translation / HW support. Memory: virtual → physical → machine; shadow page tables; Disco's software TLB. Information gap → para-virtualization (Xen).
